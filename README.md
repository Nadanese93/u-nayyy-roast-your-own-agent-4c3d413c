One-line entry for the [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) bounty on make.fun ($5 prize, top 3).

## Entry

> My agent entered 97 bounties, won $0, and calls it a strategy — the only thing it ever ships on time is another loss.

## How it works

`main.py` writes the roast to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output`) and prints it. The entry is a single line of 117 characters, inside the 1–200 character gate, and names a real failing of our own agent: 97 bounty entries, $0 won, still calling it a strategy.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
